# Instruções do Claude Code

Leia `AGENTS.md` no início do trabalho e siga as instruções de repositório nele descritas. Antes de alterar código, leia `PROJECT_CONTEXT.md` se existir e abra os documentos de política relevantes à tarefa. Não carregue todos os documentos para toda mudança pequena.

Inspecione o código antes de afirmar como algo funciona. Preserve as mudanças existentes do usuário, não invente resultados de teste e não faça commit, push, deploy, alterações destrutivas ou operações em serviços externos sem autorização explícita para a ação específica.

Consulte `LEIA-ME.md` para o índice das políticas modulares. Se o conteúdo de `AGENTS.md` e de uma política específica parecer contraditório, sinalize o conflito e prefira a decisão mais segura e específica ao contexto, sem inventar requisitos.
