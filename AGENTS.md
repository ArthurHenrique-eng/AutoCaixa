# AutoCaixa — instruções para agentes de IA

As instruções canônicas do projeto ficam em `autocaixa/Prompt/`.

Antes de alterar o projeto:
1. Leia `autocaixa/Prompt/AGENTS.md`.
2. Leia `autocaixa/Prompt/PROJECT_CONTEXT.md`.
3. Abra somente os prompts adicionais relevantes à tarefa.
4. Para alterações no AutoCaixa, leia também `autocaixa/Prompt/AUTOCAIXA_REGRAS_ESPECIFICAS.md`.

Não trate este arquivo como substituto dos prompts canônicos. Ele existe na raiz para que agentes que procuram `AGENTS.md` automaticamente encontrem a política do projeto.

Regras essenciais: preserve segurança e integridade de dados, não invente fatos sobre o ambiente, faça mudanças pequenas e reversíveis, não exponha segredos e execute as verificações pertinentes antes de declarar uma alteração concluída.
